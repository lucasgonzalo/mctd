Guía de uso

¿Qué se puede resolver?

Modelos de programación lineal escritos en lenguaje MathProg (GNU MathProg / GMPL), resueltos con GLPK (glpsol):

  • Maximizar o minimizar una función objetivo lineal sujeta a restricciones lineales.
  • Problemas clásicos de la cursada: producción, mezcla, dieta, transporte, asignación.
  • Análisis de dualidad: los precios sombra aparecen en la columna Marginal de la solución.

Ejemplo mínimo:

var x >= 0;
var y >= 0;

maximize z: x + 2*y;

s.t. restriccion: x + y <= 4;

end;

¿Dónde se guardan los archivos?

  • models/*.mod — tus modelos (se guardan con el botón Guardar o automáticamente al resolver).
  • results/{modelo}-{fecha-hora}.txt / .log — solución y log de cada ejecución.
  • models/.meta/*.json — fecha de creación de cada modelo (para el orden estable de la lista).

Todo vive en tu carpeta del proyecto fuera del contenedor Docker, así que no se pierde al reconstruir la imagen.

¿Cuántas ejecuciones se conservan?

Las últimas 5 ejecuciones por modelo. Al resolver, las corridas más viejas se borran automáticamente (historial circular). La sección Últimas ejecuciones del panel lateral muestra las 10 más recientes de todos los modelos.

Stack

  • Backend: Python + FastAPI, ejecuta glpsol (GLPK) por subprocess.
  • Frontend: una sola página HTML + JavaScript vanilla, sin build.
  • Entorno: Docker (python:3.12-slim + glpk-utils).

Cómo correr el proyecto

# arrancar (o reconstruir tras cambiar código)
docker compose up -d --build

# abrir la app
# http://localhost:8000

# frenar
docker compose down

Si el 8000 está ocupado, Docker usa el primer puerto libre del 8000–8005; verificá cuál tomó con docker compose ps.
